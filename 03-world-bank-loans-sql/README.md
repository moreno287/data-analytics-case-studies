# Financial Analysis of World Bank Loans: São Tomé and Príncipe (SQL)

**Tools:** SQL · Aggregations · Exploratory data analysis · Reporting

## Goal
Find outliers, patterns and trends in World Bank lending transactions.

## What I did
- Mined **1.2 million** World Bank loan transactions with SQL.
- Used `SELECT`, `WHERE`, `GROUP BY`, `AVG`, `MIN`/`MAX` and `SUM` to profile loans, spot outliers and track trends.
- Focused the deep-dive on São Tomé and Príncipe.
- Wrote a report of the findings.
