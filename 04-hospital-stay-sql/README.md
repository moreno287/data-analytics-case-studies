# What Drives Hospital Length of Stay? (SQL)

**Tools:** SQL (MySQL) · Exploratory data analysis · Healthcare analytics

## Goal
Understand which factors are linked to how long patients stay in hospital.

## What I did
- Analyzed records for **over 101,000 patients** in MySQL.
- Explored how length of stay relates to patient and treatment factors.
- Built a histogram of length of stay directly in SQL.
